# Turun Jeri

Site demonstrativo de uma agência fictícia de turismo em Jericoacoara.

## Executar

Abra `index.html` no navegador ou execute `iniciar-novo.cmd` e acesse http://127.0.0.1:8767/ com Python instalado.

## Recursos

- Fotografia com movimento controlado pela rolagem e três momentos de texto.
- Layout responsivo e suporte à preferência por movimento reduzido.
- Planejador local com resumo copiável. Não envia dados, não cobra e não confirma reservas.
- HTML, CSS e JavaScript sem instalação de dependências.
